# GMBot 🤖

**GMBot** est un chatbot conçu pour être aussi puissant et polyvalent que Claude, spécialisé dans :

- **Rédaction de haute qualité** (articles, emails, histoires, rapports, scripts...)
- **Grand espace de tokens** (compatible 128k–1M+ tokens)
- **Réflexion profonde** (Chain-of-Thought + Self-Reflection + Tree-of-Thought)
- **Logique avancée**
- **Résolution d'énigmes et puzzles**
- **Équations mathématiques complexes** (algèbre, calcul, analyse, équations différentielles, etc.)

## Fonctionnalités clés

- Prompt système ultra-optimisé inspiré des meilleurs modèles (Claude-level reasoning)
- Boucle de réflexion multi-étapes (analyse → raisonnement → critique → réponse finale)
- Support natif des mathématiques avec KaTeX et SymPy
- Interface CLI + Interface Web (Gradio)
- Compatible avec n'importe quel backend OpenAI-compatible (Grok, Claude via proxy, DeepSeek, Qwen, Llama 4, GLM, Ollama local, etc.)
